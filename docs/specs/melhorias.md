# Melhorias do Sistema

Documento para registro de possíveis melhorias para o sistema.

## Grupo

Seção para melhorias destinadas aos grupos

### Contas

- Permitir o lançamento de novas contas com valor = 0 (zero);

- Implementar checkbox para permitir que contas com recorrencia (permanente) possam ser iniciadas com valor = 0 (zero).

### Parcelamento

- Lançamentos do tipo Parcelado devem exibir parcela atual + restantes;

- Permitir alterações de parcelamento:
    - Validar o adiantamento de repasses para parcelados;
    - Validar o adiantamento de parcelas.

### Repasses

- Incluir cabeçalho de filtros de pesquisa na página de repasses;

- Campos de descrição de repasses:
    - Incluir origem do repasse;
    - Incluir data origem do repasse;
    - Incluir descrição do repasse.

### Membros

- Incluir tag creator para quem criou o grupo;
    - Creator sobrescreve todas as outras permissões;

- Alterar admin para adicionar/remover e dar permissões de admin para outros usuários.

### Resumo

- Tab Resumo deve ser renomeado para **Balanço**.

### Balanço

- Tab Balanço deve ser renomeado para **Histórico**.
